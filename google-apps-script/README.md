# CRM Elteca

Вкладка «Заявки» собирает заявки по пакетам и обращения со страницы «Контакты». Новые заявки получают статус «Новая». Google Apps Script записывает их в таблицу и подтверждает ID только после записи.

1. В Google Таблице оставьте общий доступ «Ограниченный». Доступ сотрудникам выдавайте по их аккаунтам.
2. В этой таблице откройте **Расширения → Apps Script** и вставьте [Code.gs](Code.gs). В настройках проекта добавьте свойство `CRM_SPREADSHEET_ID`. Его значение — ID таблицы из адреса между `/d/` и `/edit`.
3. Разверните Apps Script как веб-приложение. Выберите запуск от своего имени и доступ «Все», чтобы посетителю сайта не требовался аккаунт Google. Эта настройка открывает только веб-приложение для записи; доступ к самой таблице остаётся ограниченным.
4. Добавьте URL развёртывания с окончанием `/exec` в `crm-config.js`. Обновите версию ссылки на `crm-config.js` в обеих HTML-страницах для сброса кэша.
5. Проверьте через сайт заявку с выбранным пакетом и обычную заявку: обе должны появиться во вкладке «Заявки», а браузер должен получить подтверждение записи. Затем опубликуйте изменения в основной ветке.
