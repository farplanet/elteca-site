# Elteca — заявки в Telegram

Ветка `telegram-direct` содержит статический сайт и сервер для прямой отправки заявок через Telegram Bot API. Формы на главной и странице контактов отправляют данные на `/api/enquiry`.

На сервере нужен Node.js 24. Установите переменные окружения `ELTECA_ORIGIN` (например, `https://elteca.ru`), `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (числовой ID личного чата или группы). Токен храните в настройках запуска на сервере. Для личного чата сначала нажмите «Старт» у бота, для группы добавьте его в группу.

Запустите `node server.mjs` и направьте HTTPS-запросы домена на `127.0.0.1:3000` через веб-сервер. Порт можно задать через `PORT`. После запуска проверьте заявку на выбранный пакет и обычную заявку со страницы «Контакты».

## Переадресация старого адреса

До общего перенаправления HTTP на HTTPS и до проксирования настройте на внешнем веб-сервере точное правило для `/job.html` с ответом `301` и адресом `https://elteca.ru/`. Для Apache или LiteSpeed используйте правило из `.htaccess` в корне сайта. Node.js отдаёт тот же 301 для запросов к `/job.html`, дошедших до приложения. После выкладки проверьте оба адреса, `http://elteca.ru/job.html` и `https://elteca.ru/job.html`, без автоматического перехода по редиректу.
